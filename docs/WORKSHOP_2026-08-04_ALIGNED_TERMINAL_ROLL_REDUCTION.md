# Workshop Note: Aligned Terminal-Roll Reduction for Spatial Dexterity

**Date:** 2026-08-04  
**Status:** Revised research hypothesis and implementation handoff; not a proven dexterity criterion  
**Repository baseline:** v0.2 planar 3R work after PR #1, *Harden Grashof classification, radial mechanism atlas, and CI for v0.2*

## 1. Why this note exists

The first attempt to extend the planar 3R Grashof result directly to a spatial 6R manipulator moved too quickly. In particular, it treated the aligned-terminal pointing problem as an inherently one-degree-of-freedom `Uv + 5R` mechanism and then proposed a finite set of eight spherical four-bar fibers.

That formulation imposed an additional pointing constraint without clearly identifying it.

The corrected hierarchy is:

```text
fixed tool position
    -> n - 3 configuration DOF
quotient aligned terminal roll
    -> n - 4 position-and-pointing DOF
fix one additional independent pointing coordinate
    -> n - 5 DOF fiber
```

For a nonredundant aligned-terminal 6R manipulator, the important reduction is therefore from a three-degree-of-freedom fixed-position orientation problem to a two-degree-of-freedom pointing problem. A one-degree-of-freedom spherical four-bar can arise only as an additional constrained fiber of that two-degree-of-freedom parent.

This remains a falsifiable mechanism-construction hypothesis, not yet a research claim.

## 2. Reference theory

The relevant Grashof framework is the spherical four-bar analysis in Chapter 7 of:

J. M. McCarthy and G. S. Soh, *Geometric Design of Linkages*, Interdisciplinary Applied Mathematics, vol. 11.

The intended tests are the McCarthy-Soh spherical `T1`-`T4` linkage-type and rotatability conditions. The ordinary planar inequality

```text
shortest + longest <= remaining two links
```

is not the operative test for this spatial work.

McCarthy-Soh applies only after an actual spherical `RRRR` linkage has been established:

- four revolute axes;
- all four axes concurrent at one fixed center;
- four fixed angular link dimensions;
- one internal degree of freedom;
- a designated ground, input, coupler, and output inversion.

Correct mobility alone does not prove spherical-four-bar equivalence.

## 3. Fixed-position virtual closure for an nR manipulator

Fix the Cartesian task point `p` while leaving tool orientation unrestricted. The serial chain can be closed to ground with a virtual spherical joint at `p`:

```text
Ground - R1 - R2 - ... - Rn - Sv(p) - Ground
```

For a regular spatial chain, the generic mobility is

```text
M_position = n + 3 - 6 = n - 3.
```

This agrees with the dimension of the fixed-position configuration set

```text
C_p = {q in Q : p(q) = p}
```

when the position Jacobian has rank three.

Examples:

```text
6R + Sv -> M_position = 3
7R + Sv -> M_position = 4
```

These dimensions include all orientation motion and any internal redundancy that remains after fixing position.

## 4. Aligned terminal-roll condition

Let `d` be the selected tool-frame pointing direction expressed in the world frame. Let the terminal revolute joint `Rn` have unit axis direction `wn` and contain a point `rn`.

The aligned-terminal condition is:

```text
p lies on the Rn axis
wn is parallel to d
```

Equivalently,

```text
p - rn is parallel to wn
d is parallel to wn.
```

The translational velocity of the task point generated by `Rn` is

```text
p_dot = wn x (p - rn) = 0,
```

because `p` lies on the terminal axis.

The change in pointing direction generated by `Rn` is

```text
d_dot = wn x d = 0,
```

because the terminal axis is aligned with the tool direction.

Therefore `qn` changes neither task position nor tool pointing direction. It changes only roll about `d`.

This is stronger than merely saying that the terminal axis intersects the virtual spherical-joint center. Concurrency with the task point removes translation; alignment with the selected tool direction makes the remaining rotation pure terminal roll.

## 5. Why the terminal joint does not add a pointing DOF

The virtual spherical joint at `p` permits all rotations about axes through `p`. The rotational screw of the aligned terminal joint lies inside that spherical rotational screw space.

The terminal joint still contributes one degree of freedom to full tool orientation. However, that degree of freedom is precisely the `SO(2)` roll fiber that is factored out when the task is reduced from full orientation to position plus pointing.

Define the reduced task map

```text
Psi(q) = (p(q), d(q)).
```

Under the aligned-terminal condition,

```text
dPsi/dqn = 0.
```

Thus `qn` is a vertical or gauge direction of the reduced position-and-pointing task. The reduced configuration space is the quotient

```text
P_p = C_p / S1_roll.
```

At regular points,

```text
M_pointing = (n - 3) - 1 = n - 4.
```

In virtual-mechanism notation,

```text
(nR + Sv) / Rn  ->  (n-1)R + Sv
M_pointing = (n - 1) + 3 - 6 = n - 4.
```

This notation represents quotienting the pure-roll symmetry. It should not be read as physically deleting a joint from the full orientation mechanism.

## 6. Consequences for 6R and redundant 7R manipulators

### 6.1 Aligned-terminal 6R manipulator

```text
6R + Sv -> M_position = 3
(6R + Sv) / R6 -> 5R + Sv -> M_pointing = 2
```

The dexterity problem separates into:

1. coverage of terminal-axis pointing directions on `S2` by the two-dimensional reduced mechanism;
2. sufficient terminal-roll range from `R6` at every required pointing direction.

The reduced pointing map is

```text
Phi_p : P_p^2 -> S2.
```

A necessary local regularity condition for full pointing capability is

```text
rank(D Phi_p) = 2.
```

A global dexterity claim would additionally require complete pointing coverage, appropriate roll coverage, branch accessibility, and treatment of singularities and joint limits.

### 6.2 Aligned-terminal redundant 7R manipulator

```text
7R + Sv -> M_position = 4
(7R + Sv) / R7 -> 6R + Sv -> M_pointing = 3
```

The reduced pointing map is

```text
Phi_p : P_p^3 -> S2.
```

At a regular pointing direction, the inverse image is generically one-dimensional:

```text
dim(Phi_p^-1(d)) = 3 - 2 = 1.
```

This is the residual self-motion of the redundant arm after position and terminal roll have been accounted for.

The preferred term is `redundant 7R manipulator`, not `over-defined manipulator`.

## 7. Intersecting-axis representation of the aligned 6R pointing mechanism

After quotienting `R6`, the aligned 6R pointing parent is

```text
Sv - R1 - R2 - R3 - R4 - R5.
```

Assume two disjoint pairs of consecutive physical revolute axes intersect:

```text
(Ri, Ri+1) -> UA
(Rj, Rj+1) -> UB
remaining revolute -> RC.
```

Then the same two-degree-of-freedom parent may be represented as

```text
Sv - UA - UB - RC
```

or an `SUUR` spatial loop.

Its generic mobility is

```text
M = 3 + 2 + 2 + 1 - 6 = 2.
```

This is a representation of the reduced pointing mechanism. It is not itself a spherical four-bar, and the intersecting-axis grouping does not reduce its mobility.

## 8. One-degree-of-freedom fibers are additional slices

A spherical `RRRR` has one internal degree of freedom. Therefore it cannot directly represent the full two-dimensional pointing mechanism of an aligned 6R arm.

To obtain a one-degree-of-freedom fiber, impose one independent scalar constraint on the reduced pointing parent:

```text
F_c = {q in P_p : h(q) = c}.
```

At regular values of `c`,

```text
dim(F_c) = 2 - 1 = 1.
```

Examples of possible fiber definitions include:

- fixing one internal coordinate of the `SUUR` parent;
- constraining the pointing direction to a specified curve on `S2`;
- fixing one scalar function of the tool direction, such as `n^T d = c`;
- following an architecturally distinguished self-motion curve.

The choice of `h` must be explicit. Replacing `Sv` by a virtual universal joint `Uv` is not automatically equivalent to choosing a valid fiber. A `Uv` closure may be used only after proving that it enforces exactly the intended scalar pointing constraint without introducing coordinate artifacts.

## 9. Conditions for an exact spherical four-bar fiber

A one-dimensional fiber is not a spherical four-bar merely because four axes can be drawn at one configuration. A candidate must pass all of the following tests.

### 9.1 Exact one-dimensional parent fiber

The imposed constraint `h(q) = c` must produce a regular one-dimensional branch of the original reduced pointing mechanism. The branch must not arise only from a singular or accidentally locked configuration.

### 9.2 Four globally concurrent revolute axes

The four selected revolute axes must pass through one common fixed point `O` over the complete branch.

For an axis with point `r` and unit direction `w`, its distance to `O` is

```text
axis_distance = ||(I - w w^T)(O - r)||.
```

Pairwise intersections at different shoulder, elbow, wrist, or task centers are insufficient.

### 9.3 Fixed spherical arc dimensions

For four concurrent selected axes `a1, a2, a3, a4`, define

```text
alpha = acos(a1^T a2)
beta  = acos(a2^T a3)
gamma = acos(a3^T a4)
eta   = acos(a4^T a1).
```

These dimensions must remain constant over the full branch.

A numerical residual is

```text
arc_residual = max_s ||[alpha,beta,gamma,eta](s)
                         - [alpha,beta,gamma,eta](0)||.
```

### 9.4 Coordinate locking, when compound joints are decomposed

If a universal or spherical joint is represented through sequential revolute coordinates, every coordinate omitted from the proposed `RRRR` must remain constant along the complete branch.

A numerical residual is

```text
lock_residual = max_s ||q_inactive(s) - q_inactive(0)||.
```

This is a test of the proposed coordinate reduction, not a generic property of a universal or spherical joint.

### 9.5 Motion equivalence

The proposed spherical `RRRR` must reproduce the same one-dimensional configuration branch and output pointing motion as the constrained parent fiber.

A first local test compares null-space tangents:

```text
J_fiber(q) qdot = 0
J_4R(theta) thetadot = 0.
```

After lifting the four-bar tangent into parent coordinates, the normalized tangent directions should be parallel. A global test must then continue both mechanisms around the complete accessible branch.

Passing at one pose is insufficient.

## 10. Status of the previous eight-candidate formulation

The earlier proposal enumerated eight `RRRR` candidates by selecting one revolute coordinate from each of three universal joints in a `UUUR` one-degree-of-freedom parent.

That construction depended on the unsupported substitution

```text
5R + Sv -> 5R + Uv.
```

The corrected parent is two-dimensional and retains `Sv`:

```text
5R + Sv -> Sv - UA - UB - RC.
```

The virtual spherical joint has a continuum of possible rotational axes, not a binary axis choice. Therefore there is no architecture-independent finite set of eight fibers for the full pointing problem.

A finite axis-choice enumeration may still be useful after:

1. an explicit one-dimensional fiber has been defined;
2. a coordinate decomposition for the compound joints has been fixed;
3. the unused coordinates have been shown to lock along that fiber.

Such an enumeration would be secondary to fiber construction and may depend on the chosen coordinate convention. It should not be treated as the primary dexterity classifier.

## 11. Revised research hypothesis

> For an `nR` manipulator whose terminal revolute axis passes through the task point and is aligned with the selected tool direction, the terminal joint generates pure roll and is a symmetry of the position-and-pointing task. Quotienting this roll reduces the fixed-position mechanism from `n - 3` to `n - 4` dimensions. Consequently, an aligned-terminal 6R manipulator admits a two-dimensional pointing-space analysis, while an aligned-terminal redundant 7R manipulator admits a three-dimensional reduced analysis. For restricted architectures, one-dimensional fibers of the reduced pointing mechanism may admit exact spherical `RRRR` representations and may then be classified using the McCarthy-Soh spherical Grashof conditions.

The dimensional reduction is the primary result to establish. The spherical-four-bar fiber construction is a subsequent and narrower hypothesis.

## 12. First build: controlled aligned-terminal 6R mechanism

Do not begin with a URDF or a named industrial robot.

Construct one synthetic aligned-terminal 6R chain with:

- a fixed task point lying exactly on the `R6` axis;
- the selected tool direction exactly aligned with `R6`;
- no joint limits, collision, dynamics, or approximate axis intersections;
- two deliberately constructed intersecting-axis pairs among `R1` through `R5`;
- an explicit virtual spherical closure at the task point.

The first experiment should verify the reduction itself before attempting a spherical four-bar.

### 12.1 Stage A: verify the roll quotient

At sampled fixed-position configurations:

1. verify `dp/dq6 = 0`;
2. verify `dd/dq6 = 0`;
3. verify that `q6` changes tool roll;
4. verify that the fixed-position configuration Jacobian has nullity three;
5. verify that the position-and-pointing Jacobian has nullity two after quotienting the `q6` direction.

### 12.2 Stage B: verify the two-DOF `SUUR` representation

1. group the two intersecting physical axis pairs as `UA` and `UB`;
2. retain the remaining physical revolute as `RC`;
3. verify mobility two numerically and analytically;
4. compare the reduced `5R + Sv` parent with the `Sv-UA-UB-RC` representation;
5. verify equality of local tangent spaces and continued motions.

### 12.3 Stage C: define one explicit fiber

Choose one scalar constraint `h(q) = c` and verify that it produces a regular one-dimensional branch.

Only then:

1. search for four globally concurrent revolute axes;
2. test fixed spherical arc dimensions;
3. test omitted-coordinate locking;
4. test local and global motion equivalence;
5. apply McCarthy-Soh `T1`-`T4` only if all previous tests pass.

## 14. Falsification gates

Stop or reformulate the hypothesis if:

1. the purported aligned terminal joint changes either the task point or the selected tool direction;
2. the reduced position-and-pointing mechanism does not have dimension `n - 4` at regular configurations;
3. intersecting-axis grouping fails to reproduce the tangent space or continued motion of the original reduced chain;
4. no nondegenerate one-dimensional fiber can be defined without imposing a coordinate-artifact constraint;
5. no useful fiber admits four globally concurrent axes with fixed spherical arc dimensions;
6. an apparent `RRRR` match holds only instantaneously and fails under continuation;
7. McCarthy-Soh rotatability has no stable relationship to pointing motion along exact fibers;
8. complete fiber rotatability fails to provide useful information about global pointing coverage.

A negative result is useful if it identifies the precise obstruction.

## 15. Questions intentionally left open

- Which real 6R architectures satisfy the exact aligned-terminal condition at the chosen task point?
- Is the quotient globally well behaved across singular configurations and finite joint limits?
- Which intersecting-axis groupings produce exact `SUUR` representations rather than only local approximations?
- What scalar fiber constraints are architectural rather than arbitrary coordinate choices?
- Does a useful family of exact spherical-four-bar fibers exist over an open region of the pointing workspace?
- How should McCarthy-Soh ground, input, coupler, and output inversions be assigned for each exact fiber?
- Which `T1`-`T4` linkage types correspond to the required tool-side pointing motion?
- Can fiber classifications be assembled into a global coverage criterion on `S2`?
- How do branch connectivity, singularities, and joint limits modify the analytical result?
- What is the corresponding reduced mechanism for a redundant aligned-terminal 7R arm?
- What changes when the terminal axis intersects the task point but is not aligned with the selected tool direction?
- What changes when the task point does not lie on the terminal joint axis?
