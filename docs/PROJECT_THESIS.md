# Project Thesis

**Status:** CANONICAL  
**Project:** Characterization of Manipulator Workspaces by Kinematic Decomposition

## Preferred project description

This project characterizes manipulator orientation capability by fixing the tool
position, representing the remaining inverse-kinematic set as a virtual closed
mechanism, decomposing that mechanism into verified lower-dimensional mechanism
families where possible, and reconstructing the resulting orientation image from
certified mechanism behaviors.

## Short thesis

Dexterous-workspace characterization is a global orientation-coverage problem on
the virtual mechanism obtained after fixing tool position.

## Decomposition thesis

Kinematic decomposition converts a high-dimensional coverage problem into
lower-dimensional mechanism-behavior tests whose task images may be recombined
only under a proven coverage and compatibility contract.

## Central object

For a serial manipulator with forward kinematics

\[
g(q)=(p(q),R(q)),
\]

the fixed-position fiber at \(p^*\) is

\[
\mathcal F_{p^*}=\{q:p(q)=p^*\}.
\]

Its task-orientation image is

\[
\mathcal O(p^*)=\{R(q):q\in\mathcal F_{p^*}\},
\]

or the corresponding quotient task image when pointing rather than full
orientation is explicitly declared.

## Program thesis

Fixing position induces an exact virtual closed source mechanism. Where the
source architecture admits a valid decomposition, lower-dimensional mechanism
families may expose intrinsic behavior predicates whose task images can be
reconstructed under a proven compatibility contract.

## Role of Grashof

The planar 3R reference reduces to a one-degree-of-freedom planar four-bar, so
full \(SO(2)\) orientation coverage becomes designated-link full rotation and
admits Grashof-type analysis. This explains why Grashof appears; it does not
make a universal Grashof inequality the premise of the spatial program.

Classical Grashof classification is one mechanism-behavior description used in
the planar reference. The general program does not assume that every spatial
workspace admits one universal Grashof inequality.

## Evidence chain

```text
open serial chain
  -> fix the tool position
  -> construct the exact virtual closed source mechanism
  -> identify the remaining orientation or pointing task
  -> derive architecture- or task-grounded lower-dimensional mechanism families
  -> classify the behavior of those mechanisms
  -> prove how their task images are compatible and can be stitched together
  -> reconstruct the parent orientation image
  -> classify reachable, pointing-complete, or dexterous workspace
```

## Claim boundary

A standalone four-bar classification is not a robot-workspace result. A workspace
claim requires source-chain provenance, a valid reduction or direct source
analysis, an explicit task map, completeness/uncertainty handling, reconstruction,
and independent validation.

## Research principles

1. **Source mechanism before reduction.** Construct the fixed-position fiber or parent before proposing lower-dimensional factors.
2. **Exact closure is not decomposition.** Virtual spherical closure represents the task constraint exactly; aggregation, quotienting, slicing, and factorization require separate evidence.
3. **Dimension is necessary, not sufficient.** Matching the dimension of a target does not establish global coverage.
4. **Image and target are distinct.** The orientation set generated by a mechanism is not automatically the set required by the task.
5. **Behavior certificates, not flags.** Report designated-link rotatability, winding, circuit, completeness, and uncertainty rather than a lone “Grashof” bit.
6. **Children do not prove parents.** A collection of one-dimensional fibers or four-bars is not the higher-dimensional parent until coverage stitching and independent parent-image comparison succeed.
