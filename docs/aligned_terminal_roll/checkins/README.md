# Check-in Records

Copy `../CHECKIN_TEMPLATE.md` for each formal milestone review.

Naming convention:

```text
CHECKIN_01_TERMINAL_ROLL_SYMMETRY.md
CHECKIN_02_TWO_DIMENSIONAL_REDUCTION.md
CHECKIN_03_ARCHITECTURE_COMPARISON.md
CHECKIN_04_POINTING_MANIFOLD.md
CHECKIN_05_FIBER_LEGITIMACY.md
CHECKIN_06_SPHERICAL_EQUIVALENCE.md
CHECKIN_07_EXACT_UR_GENERALIZATION.md
```

A check-in is incomplete until it records an explicit project decision and updates the project plan, roadmap, and risk register.
