# Kinematic Decomposition of Fixed-Position Manipulator Fibers

**Status:** Working theoretical framework
**Project:** Characterization of Manipulator Workspaces
**Date:** 2026-08-07

---

## 1. Central Idea

The framework should not begin with the observation that Grashof conditions characterize the planar 3R dexterous workspace and then ask whether analogous Grashof conditions can be found for spatial 6R manipulators.

The more fundamental progression is:

1. Begin with the forward kinematics of an open-chain manipulator.
2. Fix the Cartesian position of the tool frame.
3. Study the inverse-kinematic configuration set that remains over that position.
4. Represent that fixed-position configuration set as a virtual closed mechanism.
5. Determine the orientation image generated by that mechanism.
6. Where the virtual mechanism admits a valid kinematic decomposition, analyze its lower-dimensional constituent mechanisms.
7. Use intrinsic mechanism properties—such as rotatability, circuit structure, and Grashof-type conditions—to infer orientation coverage.
8. Convert orientation coverage into a statement about dexterity or a reduced orientation task.

In compact form,

\[
\boxed{
\text{open chain}
\;\xrightarrow{\text{fix tool position}}\;
\text{fixed-position fiber}
\;\longleftrightarrow\;
\text{virtual closed mechanism}
\;\xrightarrow{\text{orientation map}}\;
\text{orientation coverage}
}
\]

Kinematic decomposition is therefore the central operation. Grashof is not the starting point. It is one possible downstream predicate for one class of decomposed mechanism.

## 2. A Necessary Terminology Correction

A manipulator with four degrees of freedom does not “reside in \(SE(4)\),” and a one-dimensional residual mechanism does not reside in \(SE(1)\).

The relevant spaces are:

- Planar rigid-body pose space:

  \[
  SE(2) \cong \mathbb{R}^2 \rtimes SO(2),
  \qquad \dim SE(2)=3.
  \]

- Spatial rigid-body pose space:

  \[
  SE(3) \cong \mathbb{R}^3 \rtimes SO(3),
  \qquad \dim SE(3)=6.
  \]

The manipulator has an \(n\)-dimensional configuration space \(Q\), while its forward-kinematic image lies in a subset of \(SE(2)\) or \(SE(3)\). The dimension of that image depends on the number and arrangement of the joints.

Likewise, fixing the tool position does not literally turn \(SE(3)\) into a smaller \(SE(k)\). Formally, it restricts the configuration space to a level set of the position map. The remaining object is a **fixed-position inverse-kinematic fiber**, not a lower-order special Euclidean group.

The intuitive statement remains useful:

> Fixing Cartesian position removes translation from the active task question and leaves the orientation behavior conditional on that position.

The more precise statement is:

> Fixing Cartesian position selects a level set in configuration space, and the orientation map restricted to that level set determines the orientation capability at the selected point.

## 3. Formal Setup

Let the forward kinematics of an \(n\)-DOF manipulator be written as

\[
g(q)=\bigl(p(q),R(q)\bigr),
\qquad q\in Q.
\]

For a planar manipulator,

\[
p(q)\in\mathbb{R}^2,
\qquad R(q)\in SO(2).
\]

For a spatial manipulator,

\[
p(q)\in\mathbb{R}^3,
\qquad R(q)\in SO(3).
\]

Choose a Cartesian tool position \(p^\ast\). The fixed-position fiber is

\[
\mathcal F_{p^\ast}
=
\{q\in Q\mid p(q)=p^\ast\}.
\]

The orientation image at that point is

\[
\mathcal O(p^\ast)
=
\{R(q)\mid q\in\mathcal F_{p^\ast}\}.
\]

This separates three different objects that should not be conflated:

1. **The fixed-position fiber** \(\mathcal F_{p^\ast}\): configurations that hold the tool point fixed.
2. **The orientation image** \(\mathcal O(p^\ast)\): orientations produced by those configurations.
3. **The coverage target**: the orientation set required by the task, such as \(SO(2)\), \(S^2\), or \(SO(3)\).

For conventional planar dexterity,

\[
p^\ast\in W_D
\quad\Longleftrightarrow\quad
\mathcal O(p^\ast)=SO(2).
\]

For conventional spatial dexterity,

\[
p^\ast\in W_D
\quad\Longleftrightarrow\quad
\mathcal O(p^\ast)=SO(3).
\]

For a pointing task that ignores roll, define

\[
\pi:SO(3)\rightarrow S^2,
\qquad
\pi(R)=R\hat z_T,
\]

where \(\hat z_T\) is the selected tool axis. Then the pointing image is

\[
\mathcal P(p^\ast)
=
\{\pi(R(q))\mid q\in\mathcal F_{p^\ast}\}
\subseteq S^2,
\]

and complete pointing coverage is

\[
\mathcal P(p^\ast)=S^2.
\]

## 4. Fiber Dimension and Virtual-Mechanism Mobility

At a regular configuration, the fixed-position fiber has dimension

\[
\dim\mathcal F_{p^\ast}
=
 n-\operatorname{rank}J_p(q),
\]

where \(J_p\) is the position Jacobian.

At a generic regular point with full translational rank,

- planar:

  \[
  \dim\mathcal F_{p^\ast}=n-2,
  \]

- spatial:

  \[
  \dim\mathcal F_{p^\ast}=n-3.
  \]

The same count appears when the tool point is closed back to ground with a virtual joint.

### 4.1 Planar closure

Fixing the planar tool point can be represented by adding a virtual revolute joint at \(p^\ast\). An open planar \(nR\) chain becomes a closed planar \((n+1)R\) mechanism with generic mobility

\[
\boxed{M=n-2.}
\]

Examples:

- planar 2R \(\rightarrow\) closed 3R triangle, \(M=0\);
- planar 3R \(\rightarrow\) closed 4R linkage, \(M=1\).

### 4.2 Spatial closure

Fixing the spatial tool origin can be represented by adding a virtual spherical joint \(S_v\) at \(p^\ast\). An open spatial \(nR\) chain becomes

\[
nR+S_v
\]

with generic mobility

\[
\boxed{M=n-3.}
\]

Examples:

- spatial 4R \(\rightarrow 4R+S_v\), \(M=1\);
- spatial 5R \(\rightarrow 5R+S_v\), \(M=2\);
- spatial 6R \(\rightarrow 6R+S_v\), \(M=3\).

Thus the mobility of the virtual closure agrees with the local dimension of the fixed-position inverse-kinematic fiber.

This agreement is the structural reason that mechanism analysis is relevant: the virtual closed mechanism is not merely an analogy. It represents the configurations that satisfy the fixed-position constraint.

The mobility count is generic. Singular configurations, dependent constraints, special overconstraints, joint limits, and disconnected assembly modes may alter the local or global structure.

## 5. The Revised Ladder

The previous phrase **“natural remaining task”** mixed together two different ideas:

- the orientation set that the fixed-position mechanism can actually generate; and
- the orientation set that an application asks it to cover.

The ladder is clearer if those are separated.

| Open chain | Virtual fixed-position closure | Generic mobility | Maximum-dimensional orientation image at fixed position | Appropriate coverage question |
|---|---:|---:|---|---|
| Planar 2R | closed 3R triangle | 0 | A zero-dimensional, generally finite subset of \(SO(2)\) | No continuous orientation sweep is available at a regular point. |
| Planar 3R | closed 4R | 1 | A one-dimensional subset of \(SO(2)\), potentially all of \(SO(2)\) | Does the virtual 4R generate every planar orientation? |
| Spatial 4R | \(4R+S_v\) | 1 | A curve \(C_{p^\ast}\subset SO(3)\) | Does it cover a specified one-parameter orientation family? It cannot generically cover all of \(SO(3)\). |
| Spatial 5R | \(5R+S_v\) | 2 | A surface-like subset \(\Sigma_{p^\ast}\subset SO(3)\); its pointing projection lies in \(S^2\) | If roll is ignored, does the pointing image cover all of \(S^2\)? It cannot generically cover all of \(SO(3)\). |
| Spatial 6R | \(6R+S_v\) | 3 | A three-dimensional subset of \(SO(3)\), potentially all of \(SO(3)\) | Does the fixed-position mechanism generate every spatial orientation? |
| Spatial 6R with aligned terminal roll factored out | \((6R+S_v)/R_6\rightarrow 5R+S_v\) | 2 nontrivial DOFs plus an explicit roll DOF | Pointing image in \(S^2\), together with an \(S^1\) roll fiber | Does the reduced mechanism cover \(S^2\), and is full roll available over every pointing direction? |
| Spatial 7R | \(7R+S_v\) | 4 | Potentially all of \(SO(3)\), with at least one additional self-motion coordinate at a regular pose | Can full orientation be maintained while preserving a continuous redundancy motion? |

## 6. Why the Rows Differ

### 6.1 Planar 3R: why \(SO(2)\)?

The complete orientation space of a planar rigid body is \(SO(2)\), which is one-dimensional.

A regular planar 3R chain has a one-dimensional fixed-position fiber:

\[
3-2=1.
\]

Therefore the dimension of the available mechanism motion matches the dimension of the full planar orientation target:

\[
\dim\mathcal F_{p^\ast}
=
\dim SO(2)
=1.
\]

This does **not** mean that the manipulator automatically reaches every element of \(SO(2)\). Its orientation image may be only an interval, an arc modulo \(2\pi\), a disconnected set, or a full circle. The coverage problem is precisely to decide whether

\[
\mathcal O(p^\ast)=SO(2).
\]

Closing the tool point produces a 1-DOF virtual 4R. Tool orientation becomes the rotation of a designated link of that 4R, up to a fixed offset. Complete planar orientation coverage therefore becomes a complete-rotation question for the virtual mechanism. This is why four-bar rotatability and Grashof-type classification enter naturally.

### 6.2 Spatial 4R: why a one-dimensional orientation curve?

The full spatial orientation space remains \(SO(3)\), which is three-dimensional. Fixing position on a regular spatial 4R leaves only

\[
4-3=1
\]

configuration degree of freedom.

A one-dimensional configuration family can map into \(SO(3)\) only as a one-dimensional image, generically a curve:

\[
C_{p^\ast}=R(\mathcal F_{p^\ast})\subset SO(3).
\]

There is no universal reason for this curve to equal rotations about one fixed axis. It may do so for a special architecture, but in general it is simply a mechanism-dependent path through \(SO(3)\).

Therefore “one-dimensional orientation curve” describes the **orientation image**, not a universal task. An application could define a one-parameter orientation task and ask whether the curve covers it, but full spatial dexterity is dimensionally impossible for a generic 4R chain.

### 6.3 Spatial 5R: why is \(S^2\) relevant?

Fixing position on a regular spatial 5R leaves

\[
5-3=2
\]

configuration degrees of freedom. The resulting orientation image is at most two-dimensional inside the three-dimensional group \(SO(3)\).

A generic two-dimensional subset of \(SO(3)\) is not automatically \(S^2\), and it is not automatically a pure pointing set. However, \(S^2\) is the canonical reduced orientation target obtained when roll about a selected tool axis is ignored:

\[
SO(3)/SO(2)\cong S^2.
\]

Thus a spatial 5R has the correct residual dimension to attempt complete **position-plus-pointing** coverage:

\[
\dim\mathcal F_{p^\ast}=2
=
\dim S^2.
\]

The correct question is not whether the 5R covers all spatial orientations. It is whether the pointing projection covers every direction:

\[
\mathcal P(p^\ast)=S^2.
\]

This is a task choice, not an automatic property of every 5R architecture.

### 6.4 Spatial 6R: why \(SO(3)\)?

Fixing position on a regular spatial 6R leaves

\[
6-3=3
\]

configuration degrees of freedom. Since

\[
\dim SO(3)=3,
\]

the fixed-position mechanism has enough local dimension to cover the complete spatial orientation group.

Again, this is necessary but not sufficient. Joint limits, singularities, disconnected components, architecture, and mechanism topology can prevent global coverage. The dexterity question is

\[
\mathcal O(p^\ast)=SO(3)?
\]

This is the first nonredundant spatial serial case in which conventional full dexterity is dimensionally possible.

## 7. A Compact Dimensional Ladder

For a regular manipulator, a necessary dimensional condition for covering an orientation target \(Y\) while holding Cartesian position fixed is

\[
\boxed{
 n-d_p\geq \dim Y,
}
\]

where \(d_p=2\) for planar position and \(d_p=3\) for spatial position.

This produces the minimum-DOF ladder:

| Task | Position dimension \(d_p\) | Orientation target | Target dimension | Minimum generic joint DOF |
|---|---:|---|---:|---:|
| Planar position only | 2 | none | 0 | 2 |
| Planar position plus arbitrary orientation | 2 | \(SO(2)\) | 1 | 3 |
| Spatial position plus one-parameter orientation family | 3 | specified 1D family | 1 | 4 |
| Spatial position plus arbitrary pointing | 3 | \(S^2\) | 2 | 5 |
| Spatial position plus arbitrary full orientation | 3 | \(SO(3)\) | 3 | 6 |
| Spatial full pose plus one redundant self-motion DOF | 6 total pose constraints | full pose fixed | — | 7 |

This dimensional ladder explains why 2R, 3R, 4R, 5R, and 6R cases appear in a rational sequence. It identifies what is dimensionally possible before any mechanism-specific property is applied.

Dimension alone does not establish coverage. It only identifies which coverage questions are possible.

## 8. The Aligned Terminal-Roll 6R Case

The aligned terminal-roll case is a structured decomposition of the 6R orientation problem, not a claim that a generic 6R has only two residual degrees of freedom.

For a generic 6R fixed at \(p^\ast\),

\[
6R+S_v,
\qquad M=3.
\]

Spatial orientation can be projected to tool-axis direction through

\[
\pi:SO(3)\rightarrow S^2,
\qquad
\pi(R)=R\hat z_T.
\]

For a fixed pointing direction, the remaining orientations differ by roll about that axis. This roll family is isomorphic to

\[
SO(2)\cong S^1.
\]

Thus \(SO(3)\) may be viewed as an \(S^1\) roll fiber over the pointing sphere \(S^2\). It should not be treated globally as the simple Cartesian product \(S^2\times S^1\), but the pointing-plus-roll decomposition is still the correct geometric structure.

Suppose the sixth revolute joint satisfies all of the following:

1. its axis is coincident with the selected tool roll axis;
2. the tool origin lies on that axis, so the joint does not change tool position;
3. changing \(q_6\) does not change the pointing direction \(R\hat z_T\);
4. its joint range supplies the required roll coverage;
5. its roll action is not defeated by coupling, limits, or inaccessible assembly components.

Then \(R_6\) parameterizes the roll fiber directly and can be factored from the nontrivial pointing analysis:

\[
\boxed{
(6R+S_v)/R_6
\longrightarrow
5R+S_v,
\qquad M:3\rightarrow2.
}
\]

The reduced mechanism is analyzed for complete pointing coverage:

\[
\mathcal P(p^\ast)=S^2.
\]

The terminal joint is separately verified for complete roll coverage over each pointing direction.

Under those conditions, full orientation coverage is assembled from:

\[
\boxed{
\text{complete pointing coverage}
+
\text{complete terminal roll coverage}
\Longrightarrow
\text{complete spatial orientation coverage}.
}
\]

The reduction therefore does not discard a degree of freedom. It isolates a degree of freedom whose geometric action is already understood.

## 9. Kinematic Decomposition

The fixed-position closure establishes the correct residual mechanism. The next problem is whether that mechanism can be transformed into analyzable lower-dimensional components.

Several distinct operations may be involved.

### 9.1 Constraint-induced closure

The open chain is closed at the selected Cartesian point using a virtual revolute or spherical joint. This produces the exact fixed-position mechanism to be analyzed.

### 9.2 Symmetry quotient

A joint whose action lies entirely in a known task-space symmetry may be factored out. The aligned terminal roll is the primary example:

\[
SO(3)\rightarrow S^2
\]

forgets roll, while \(R_6\) supplies the corresponding \(S^1\) fiber.

### 9.3 Architecture-aware joint aggregation

Coincident or properly aligned revolute axes may admit an equivalent reduced representation. Intersecting revolute axes may, under appropriate geometric conditions, be grouped as universal or spherical joint structures.

These reductions must preserve the actual configuration set and task map. Visual similarity or equal mobility is not enough.

### 9.4 Mechanism factorization

A higher-mobility virtual mechanism may sometimes admit decomposition into coupled one-degree-of-freedom mechanisms. This is the point at which planar or spherical four-bar families may emerge.

However,

\[
\dim\mathcal C=2
\]

does not by itself imply

\[
\mathcal C\cong\mathcal C_1\times\mathcal C_2.
\]

A 2-DOF mechanism is not automatically two independent 1-DOF four-bars, and a 3-DOF mechanism is not automatically three independent 1-DOF four-bars.

A valid decomposition must establish at least one of the following:

- an exact product structure;
- a sequential or fibered structure;
- an equivalent constraint elimination;
- a coordinate transformation that preserves feasible configurations;
- a proven correspondence between component rotatability and global orientation coverage.

Coupling and compatibility conditions must be carried through the recombination.

This is an important boundary between the established framework and the current research hypothesis.

## 10. Why Grashof Appears in the Planar 3R Case

For the planar 3R chain:

1. fixing the tool point creates a virtual 4R loop;
2. that loop has one degree of freedom;
3. planar orientation is also one-dimensional;
4. tool orientation is represented by the angular motion of a designated virtual link;
5. full orientation coverage requires that angular variable to complete a full revolution;
6. complete link rotation is an intrinsic four-bar mechanism property.

Therefore Grashof-type analysis appears because the fixed-position inverse-kinematic problem **is** a one-DOF four-bar rotatability problem.

The correct logical direction is

\[
\boxed{
\text{fixed-position 3R}
\Rightarrow
\text{virtual 4R}
\Rightarrow
\text{link-rotation coverage}
\Rightarrow
\text{Grashof-type classification}.
}
\]

It is not

\[
\text{Grashof works for four-bars}
\Rightarrow
\text{try to force all manipulators into four-bars}.
\]

Classical Grashof inequalities may still need to be supplemented by link identity, assembly mode, circuit, branch, and joint-limit information before they provide a complete dexterity decision.

## 11. Extending the Logic to Spatial Chains

The spatial extension follows the same first principles:

\[
\boxed{
\text{fix position}
\Rightarrow
nR+S_v
\Rightarrow
M=n-3
\Rightarrow
\text{orientation image of that mechanism}.
}
\]

What changes is that the residual mechanism is no longer automatically a conventional one-DOF four-bar.

- A spatial 4R produces an \(M=1\) closure whose orientation image is a curve in \(SO(3)\).
- A spatial 5R produces an \(M=2\) closure that may be studied for pointing coverage in \(S^2\).
- A generic spatial 6R produces an \(M=3\) closure that must be studied for full \(SO(3)\) coverage.
- An aligned-roll 6R permits a symmetry quotient that reduces the nontrivial problem to the \(M=2\) pointing case.

The research program is then to determine which robot architectures allow these residual mechanisms to be decomposed into recognizable mechanism families and which intrinsic properties of those families imply global orientation coverage.

A spatial Grashof-like condition may emerge, but it is an output of this program rather than its premise.

## 12. Analytical Structure and Numerical Mechanism Predicates

The framework remains meaningful even if no closed-form Grashof inequality is available for every spatial mechanism family.

The following parts can be analytical:

- the fixed-position fiber definition;
- the virtual closure construction;
- the mobility and dimension count;
- the orientation or pointing coverage criterion;
- the symmetry quotient;
- the equivalence conditions for a proposed decomposition.

The final mechanism predicate may be either analytical or numerical:

- analytical Grashof-type inequalities for known mechanism families;
- exact continuation or root-solving for a specific spatial mechanism;
- a numerical crank/rotatability atlas with confidence and fallback evaluation.

Thus a defensible formulation is

\[
\boxed{
\text{analytical kinematic reduction and coverage definition}
+
\text{analytical or numerical mechanism predicate}.
}
\]

The characterization can still be mechanism-based and semi-analytical even when the family-specific rotatability decision is numerical.

## 13. Interpretation of the Current Implementation Results

This framework changes how the existing experiments should be interpreted.

### 13.1 Constructed one-dimensional pointing fibers

The ability to construct and continue explicit one-dimensional pointing fibers is meaningful. It demonstrates local fixed-task structure inside the reduced mechanism.

However, a one-dimensional family by itself does not establish:

- complete \(S^2\) pointing coverage;
- global connectivity;
- an exact four-bar equivalence;
- independent factorization of a 2-DOF mechanism;
- full \(SO(3)\) dexterity after roll is restored.

It is evidence about the local fiber structure, not yet a global coverage theorem.

### 13.2 Failed spherical-four-bar candidates

If topology-derived spherical-four-bar candidates fail decisively, that does not invalidate the fixed-position closure framework.

It invalidates—or at least strongly challenges—the proposed mechanism factorization, axis correspondence, or equivalence map for those candidates.

This is a productive distinction:

\[
\boxed{
\text{closure framework may be correct}
\quad\text{while}\quad
\text{a proposed decomposition is wrong}.
}
\]

The implementation should therefore visualize and validate each reduction step independently rather than judging the entire framework through the final four-bar candidate alone.

## 14. Visualization Sequence Implied by the Framework

A graphical implementation should follow the actual logic of the theory.

### Stage 1 — Open-chain forward kinematics

- Select a representative joint configuration.
- Plot all physical links, revolute axes, joint frames, and the tool frame.
- Display the tool position \(p^\ast\) and orientation \(R\).

### Stage 2 — Fix the tool point

- Pin the tool origin at \(p^\ast\).
- Display the translational constraint explicitly.
- Show that subsequent configurations lie in \(\mathcal F_{p^\ast}\).

### Stage 3 — Add the virtual closure

- Add the virtual planar revolute joint or spatial spherical joint at \(p^\ast\).
- Render the resulting closed mechanism over the transparent physical manipulator.
- Annotate its generic mobility \(M=n-2\) or \(M=n-3\).

### Stage 4 — Display the residual orientation image

- Planar: plot the achieved angle set in \(SO(2)\).
- Spatial 4R: plot the orientation curve in a suitable orientation representation.
- Spatial 5R or reduced 6R: plot the tool-axis pointing image on \(S^2\).
- Spatial 6R: display sampling or charts of the orientation image in \(SO(3)\).

### Stage 5 — Factor known task symmetries

- For the aligned terminal-roll case, animate \(q_6\) while holding tool position and pointing direction fixed.
- Show that \(q_6\) moves only along the roll fiber.
- Remove or ghost that joint to reveal the reduced \(5R+S_v\) pointing mechanism.

### Stage 6 — Apply architecture-aware reductions

- Identify coincident, parallel, or intersecting axes.
- Show each proposed \(R\rightarrow U\) or \(R\rightarrow S\) aggregation separately.
- Preserve the original manipulator as a transparent reference.
- Explicitly display which constraints and transforms are claimed to remain equivalent.

### Stage 7 — Propose one-DOF mechanism factors

- Render each candidate planar or spherical four-bar.
- Show its links, axes, closure constraints, and designated input/output variables.
- Do not yet apply Grashof or rotatability conclusions.

### Stage 8 — Validate the decomposition

- Reconstruct configurations of the original fixed-position mechanism from the candidate factors.
- Compare position, pointing, orientation, and closure residuals.
- Reject candidates that fail exact geometric correspondence.

### Stage 9 — Apply intrinsic mechanism properties

- Evaluate rotatability, circuits, branches, singularities, and Grashof-type predicates.
- Combine constituent results only after compatibility has been demonstrated.
- Map the result back to orientation coverage and then to workspace classification.

This sequence makes the implementation diagnostic. A failure can be localized to closure, quotient, axis reduction, mechanism factorization, component predicate, or recombination.

## 15. Claims Supported by the Framework

The following claims are structurally well grounded, subject to regularity assumptions:

1. Fixing Cartesian tool position produces an inverse-kinematic fiber.
2. The fixed-position fiber can be represented by a virtual closed mechanism.
3. The generic mobility is \(n-2\) for planar position constraints and \(n-3\) for spatial position constraints.
4. Dexterity is a global orientation-coverage property of that fixed-position mechanism.
5. A planar 2R has no continuous fixed-position orientation degree of freedom at a regular point.
6. A planar 3R produces a 1-DOF virtual 4R, explaining the relevance of four-bar rotatability.
7. A generic spatial 4R can produce only a one-dimensional orientation image at fixed position.
8. A generic spatial 5R has the correct residual dimension for a position-plus-pointing task but not for full spatial orientation.
9. A generic spatial 6R has the correct residual dimension for full \(SO(3)\) coverage.
10. An aligned terminal roll may be factored from the pointing problem when its geometric action and range satisfy the required conditions.

## 16. Research Hypotheses and Proof Obligations

The following should remain explicitly identified as hypotheses or architecture-dependent claims:

1. A given spatial \(nR+S_v\) closure can be reduced through axis alignment to a specified \(S\), \(U\), and \(R\) topology.
2. The reduced topology is exactly equivalent to the original fixed-position mechanism.
3. An \(M=2\) or \(M=3\) mechanism can be decomposed into one-degree-of-freedom four-bar mechanisms.
4. The constituent mechanisms are independent or combine through a known fibered structure.
5. Constituent crank or rotatability properties are sufficient for global \(S^2\) or \(SO(3)\) coverage.
6. Assembly circuits and branches can be combined without hidden compatibility failures.
7. Joint limits and singularities do not destroy the required global coverage.
8. A numerical spatial crank atlas classifies the exact mechanism property needed by the orientation-coverage theorem.

These are not weaknesses in the framework. They define the scientific work required to turn the framework into an analytical or semi-analytical characterization method.

## 17. Candidate Paper-Level Formulation

> Fixing the Cartesian position of a serial manipulator restricts its configuration space to an inverse-kinematic fiber that can be represented as a virtual closed mechanism. The mobility of this mechanism equals the residual configuration freedom available for orientation generation. Dexterity is therefore a global coverage property of the orientation map induced by the fixed-position mechanism. For planar 3R manipulators, the virtual mechanism is a one-degree-of-freedom four-bar, so complete planar orientation coverage reduces naturally to a link-rotatability problem and admits Grashof-type characterization. For spatial manipulators, the same construction yields higher-mobility virtual mechanisms whose orientation images are curves, pointing surfaces, or full subsets of \(SO(3)\), depending on manipulator degree of freedom and task quotient. Architecture-dependent kinematic decomposition can then expose lower-dimensional mechanism families whose intrinsic properties support analytical or numerical workspace classification.

A shorter thesis statement is:

\[
\boxed{
\text{Dexterous-workspace characterization is the study of global orientation coverage generated by the virtual mechanism obtained after fixing tool position.}
}
\]

And the role of decomposition is:

\[
\boxed{
\text{Kinematic decomposition converts a high-dimensional coverage problem into mechanism-property tests whose results can be recombined under proven compatibility conditions.}
}
\]

## 18. Final Ladder Summary

The clean conceptual progression is:

\[
\begin{aligned}
\text{planar 2R:}&&M=0
&\Rightarrow \text{no continuous orientation freedom},\\
\text{planar 3R:}&&M=1
&\Rightarrow \text{possible coverage of }SO(2),\\
\text{spatial 4R:}&&M=1
&\Rightarrow \text{orientation curve in }SO(3),\\
\text{spatial 5R:}&&M=2
&\Rightarrow \text{possible pointing coverage of }S^2,\\
\text{spatial 6R:}&&M=3
&\Rightarrow \text{possible full coverage of }SO(3),\\
\text{aligned-roll 6R:}&&M=2+1
&\Rightarrow \text{pointing }S^2\text{ plus explicit roll }S^1,\\
\text{spatial 7R:}&&M=4
&\Rightarrow \text{full orientation plus redundancy}.
\end{aligned}
\]

The progression does not assert that dimensional possibility guarantees coverage. It identifies the correct residual mechanism and the correct coverage question at each level. Intrinsic mechanism properties then determine whether the possible coverage is actually achieved.

## 19. Architecture-Derived Mechanism Hierarchy for the Software Program

The dimensional ladder becomes more concrete when exact physical axis aggregations are kept separate from task slicing.

### 19.1 Spatial 4R source: direct one-DOF mechanism

Fixing position gives

\[
4R+S_v,
\qquad M=1.
\]

No pointing slice is required. If two consecutive physical revolute axes intersect orthogonally, they may be exactly regrouped as a universal joint:

\[
RR\longleftrightarrow U.
\]

The source closure may then take a one-degree-of-freedom role-aware form

\[
S_v U_{\mathrm{phys}} R R,
\]

with variants `S_v-U_phys-R-R`, `S_v-R-U_phys-R`, and `S_v-R-R-U_phys` according to which physical pair is aggregated. This is the cleanest first spatial test because the reduced mechanism can be compared directly against the complete source fiber. A cyclically equivalent joint-kind string is not sufficient identity: `S_v` remains the tool-position closure and `U_phys` remains a physical axis aggregate.

### 19.2 Spatial 5R source: two-DOF parent mechanisms

Fixing position gives

\[
5R+S_v,
\qquad M=2.
\]

Exact physical axis aggregation may produce architecture-derived parents such as

\[
S_v U_{\mathrm{phys}} U_{\mathrm{phys}} R
\]

or

\[
S_v S_{\mathrm{phys}} R R,
\]

again up to cyclic order. These are two-degree-of-freedom parent mechanisms, not one-degree-of-freedom four-bars.

Their complete orientation and pointing images should be established before introducing scalar slices or factorization claims.

### 19.3 Task-derived one-DOF children

For the aligned-roll 6R case, an accepted terminal-roll quotient produces the same class of two-degree-of-freedom 5R pointing parent:

\[
(6R+S_v)/R_6
\longrightarrow
5R+S_v.
\]

An explicit regular scalar pointing constraint then reduces the parent by one degree of freedom. On that level set, the virtual spherical closure may be represented by a virtual universal joint:

\[
S_v
\xrightarrow{\text{task-derived slice}}
U_v.
\]

Combining that task-derived \(U_v\) with exact physical axis aggregations produces role-aware children of the classes `U_v-U_phys-U_phys-R` and `U_v-S_phys-R-R`. Their joint-kind strings form the one-degree-of-freedom families

```text
UUUR, UURU, URUU,
USRR, URSR, URRS.
```

This explains their logical position:

```text
spatial 4R source
  -> direct M=1 source fiber
  -> possible role-aware S_v U_phys R R mechanism

spatial 5R source
  -> M=2 parent
  -> possible S_v-U_phys-U_phys-R / S_v-S_phys-R-R parent

aligned-roll 6R
  -> quotient to the 5R parent
  -> explicit pointing level set
  -> S_v becomes U_v on the level set
  -> U_v-U_phys-U_phys-R / U_v-S_phys-R-R one-DOF child
```

For software, every mechanism record therefore stores both a joint-kind sequence and a joint-role sequence. In particular, V05 `S_v-U_phys-R-R` must not inherit the `tool_a`/`tool_b` semantics of a V08 `U_v-...` child merely because a cyclic topology string matches.

The child family classification is therefore downstream of:

1. the source fixed-position mechanism;
2. exact physical axis aggregation;
3. terminal-roll quotient where applicable;
4. an explicit pointing level-set constraint;
5. parent-child equivalence.

This hierarchy is the basis for the restructured V05–V09 software program.
