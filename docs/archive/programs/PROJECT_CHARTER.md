# Project Charter

## Working title

**Back to Grashof: Kinematic Decomposition for Analytical Workspace Characterization**

## Problem statement

Robot orientation capability and dexterous workspaces are commonly evaluated numerically even when the manipulator architecture may support a lower-dimensional mechanism description.

This project studies the configuration set that remains after the tool position is fixed. For a serial manipulator with forward kinematics

\[
g(q)=\bigl(p(q),R(q)\bigr),
\]

the fixed-position fiber at \(p^*\) is

\[
\mathcal F_{p^*}
=
\{q:p(q)=p^*\}.
\]

Its orientation image is

\[
\mathcal O(p^*)
=
\{R(q):q\in\mathcal F_{p^*}\}.
\]

Fixing position can be represented exactly by a virtual closed mechanism. The project asks whether architecture-dependent kinematic decomposition can expose lower-dimensional mechanism families whose intrinsic properties determine the relevant orientation coverage.

The central chain of reasoning is:

```text
open serial chain
  -> fix tool position
  -> exact virtual closure
  -> fixed-position fiber/parent
  -> orientation or pointing image
  -> validated kinematic decomposition
  -> intrinsic mechanism predicate
  -> coverage reconstruction
  -> workspace classification
```

## Trusted reference case

The planar 3R manipulator is the solved reference construction:

1. fixing the planar tool point closes the serial chain into a one-degree-of-freedom planar four-bar;
2. the remaining task target is \(SO(2)\);
3. complete planar orientation becomes complete rotation of a designated virtual link;
4. exact interval containment determines rotatability;
5. conventional Grashof classification remains supporting metadata rather than the workspace definition.

This case explains why Grashof appears. It does not imply that every spatial problem should begin by searching for a Grashof analogue.

## Spatial program thesis

At regular fixed-position configurations:

```text
spatial 4R -> 4R + S_v, M = 1 -> orientation curve in SO(3)
spatial 5R -> 5R + S_v, M = 2 -> orientation surface / pointing image in S^2
spatial 6R -> 6R + S_v, M = 3 -> possible full orientation image in SO(3)
```

The active program walks this ladder from 4R to 5R to 6R before applying broad spatial-four-bar classification.

The aligned-terminal-roll 6R case is treated as a special quotient only when its geometric action, reconstruction map, joint range, component correspondence, and pointing invariance are verified.

## Research principles

1. **Source mechanism before reduction.** Construct the fixed-position fiber or parent before proposing lower-dimensional factors.
2. **Exact closure is not decomposition.** The virtual spherical closure represents the task constraint exactly; axis aggregation, quotienting, slicing, and factorization require separate evidence.
3. **Dimension is necessary, not sufficient.** Matching the dimension of a target does not establish global coverage.
4. **Image and target are distinct.** The orientation set generated by a mechanism is not automatically the set required by the task.
5. **Components matter.** Continuation on one component does not establish a result for the full fiber.
6. **Predicates are link- and task-specific.** A generic mechanism label is not a substitute for the exact property required by the workspace theorem.
7. **Numerical predicates may support structural theory.** A structurally derived reduction may use an exact numerical mechanism evaluator while remaining explicit about what is analytical, numerical, or unresolved.
8. **Independent validation is mandatory.** Coverage reconstructed from reduced mechanisms must be checked against a source-chain orientation reference that does not use the same decomposition.

## Software evidence chain

The repository shall preserve:

```text
OpenChainModel
  -> FixedPositionProblem
  -> VirtualClosureResult
  -> FixedPositionFiberResult / FixedPositionParentResult
  -> OrientationImageResult / PointingImageResult
  -> DecompositionCertificate
  -> MechanismPredicateResult
  -> CoverageCertificate
  -> WorkspaceClassification
```

Every result retains source geometry, task definition, component identity, coordinate maps, residuals, confidence, and unresolved reasons.

## Definition of success for the active spatial phase

The active spatial phase succeeds when the repository can:

1. construct and visualize fixed-position source mechanisms for representative 4R, 5R, and 6R chains;
2. represent their orientation or pointing images with component and uncertainty metadata;
3. certify or reject proposed axis aggregations, quotients, slices, and mechanism factorizations;
4. apply an exact or qualified numerical predicate only to certified mechanisms;
5. reconstruct a source orientation-capability result through an explicit compatibility law;
6. agree with an independent source-chain numerical reference within documented tolerances;
7. preserve failures as localized evidence rather than force them into a binary workspace claim.
