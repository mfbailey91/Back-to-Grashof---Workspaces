Project question

Fix the tool position, form the exact virtual closed source mechanism, then ask whether architecture- or task-derived lower-dimensional mechanism families can certify behavior whose task images reconstruct the parent orientation or pointing image under an explicit stitching contract. 

open chain
  → fixed-position fiber / parent
  → exact virtual closure
  → orientation or pointing image
  → certified decomposition (when valid)
  → mechanism behavior certificate
  → coverage / compatibility stitching
  → independent validation

Classical Grashof classification is one planar four-bar behavior descriptor. The program does not assume a universal spatial Grashof inequality.
